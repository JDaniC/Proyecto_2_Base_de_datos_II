# Auditorías de alcance · Veredicto de CodeRabbit

**Fecha** 07/11/2026, Guatemala. **Base** `0f6d245`. **Alcance** configuración versionada, evaluador de GitHub, eventos, contrato del PR y documentación operativa. Las pruebas con escrituras usan dobles. La comprobación contra GitHub consultó datos del repositorio mediante la API en modo lectura.

## Hallazgo y corrección

El PR #78 en `7f4243b` tenía check nativo `success`, revisión `CHANGES_REQUESTED` y una solicitud de fusión automática habilitada. El script anterior publicaba `revision-coderabbit=success` al ver solo el check. La regresión aislada comprueba que el evaluador corregido publica fallo y pide retirar la solicitud. GitHub mantenía el PR bloqueado con hilos pendientes. [PR #78](https://github.com/JDaniC/Proyecto_2_Base_de_datos_II/pull/78)

## Auditoría funcional · PASS del cambio

| Requisito | Unidad y frontera | Evidencia |
|---|---|---|
| Check nativo exitoso y aprobación decisiva del commit actual | `checks_for`, `verdict` | Éxito, check ausente/no confiable/anterior, pendiente, fallido, neutro, omitido y ejecución nueva pendiente. |
| Cambios solicitados o aprobación inválida mantienen el control cerrado | `verdict`, `process` | Aprobación anterior, otro actor, comentario, revisión descartada, solicitud posterior y regresión #78. |
| Evaluar cada PR vigente y conservar la decisión entre eventos | `eligible`, `candidates`, `main`, workflows | Paginación, prioridad manual, borrador/fork/destino inválido, señal de revisión y relectura de los PR elegibles. |
| Las solicitudes de fusión se aplican al SHA verificado | `process`, CLI y API | Aprobación posterior en otra página, carrera de cambio de SHA, error de dependencia y control de commits compartidos entre PR abiertos. |
| Configuración de revisión compatible con destinos y contrato de PR | `.coderabbit.yaml`, `validar_pr.py`, plantilla | Esquema oficial válido, revisión de `develop` como rama predeterminada y `main` explícita. La excepción CONFIG-GITHUB admite el archivo exacto y conserva el rechazo de código de aplicación. |
